# BadaMobile 요구사항 정의서

> 1단계: 요구사항 도출 → 2단계: 요구사항 분석(우선순위·수용기준) 순으로 정리한다.
> 초기 버전(v0.1)은 **Android 무료 앱** 기준이며, iOS 확장을 전제로 플랫폼 종속 요구를 최소화한다.

---

## 1. 요구사항 도출

### 1.1 제품 비전

바다타임(물때·조석)과 윈디(바람·해양 날씨 시각화)의 핵심 가치를 하나의 무료 앱으로 제공한다.
"바다에 나가기 전 이 앱 하나만 보면 된다"가 목표다.

### 1.2 타깃 사용자 (페르소나)

| 페르소나 | 특성 | 핵심 니즈 |
|---|---|---|
| 갯바위/선상 낚시인 | 40~60대, 주말 출조, 물때에 민감 | 물때(사리/조금), 만조·간조 시각, 바람·파고로 출조 판단 |
| 갯벌 체험 가족 | 30~40대, 비정기 방문 | 간조 시각과 안전한 입·퇴수 시간, 날씨 |
| 서퍼/패들보더 | 20~30대, 스팟 중심 | 파고·주기·바람 방향, 시간대별 변화 그래프 |
| 소형 보트/요트 운항자 | 전 연령 | 풍속·돌풍·파고 예보, 기상 악화 경보 |

### 1.3 이해관계자 인터뷰/벤치마킹에서 도출한 원시 요구 (Raw Needs)

바다타임 벤치마킹:
- R-01 지역(포인트)별 오늘의 물때(1물~13물, 조금, 무시) 표시
- R-02 만조/간조 시각과 조위(cm) 목록
- R-03 하루 조위 변화 곡선 그래프
- R-04 날짜 이동(전날/다음날) 및 주간 조회
- R-05 음력 날짜 표시
- R-06 지역 검색과 즐겨찾기

윈디 벤치마킹:
- R-07 시간대별 풍향·풍속·돌풍 예보
- R-08 파고·파주기·수온 예보
- R-09 바람 흐름 애니메이션 지도(파티클)
- R-10 예보 모델 시각화(그래프/타임라인)

공통/신규:
- R-11 홈에서 "오늘의 바다" 요약(물때+날씨 한눈에)
- R-12 오프라인에서 마지막 조회 데이터 열람
- R-13 위험 기상(강풍·풍랑) 알림
- R-14 무료 제공, 광고는 사용성 해치지 않는 수준(초기 버전은 광고 없음)

## 2. 요구사항 분석

### 2.1 기능 요구사항 (FR) — MoSCoW 우선순위

| ID | 요구사항 | 우선순위 | 수용 기준(AC) | 상태 |
|---|---|---|---|---|
| FR-01 | 지역별 일간 물때 표시 (7물때식) | Must | 선택 지역·날짜의 물때 명칭과 음력 일자가 표시된다 | 구현(근사 음력) |
| FR-02 | 만조/간조 시각·조위 목록 | Must | 하루 3~4회 극값이 시간순으로 표시된다 | 구현(목 데이터) |
| FR-03 | 일간 조위 곡선 그래프 | Must | 0~24시 곡선과 현재 시각선이 그려진다 | 구현 |
| FR-04 | 날짜 이동(연도/월/일 계층 + 전후 화살표) | Must | 연도·월 탭 이동, 일 좌우 스크롤, 진입 시 오늘 날짜 기본 선택 | 구현 |
| FR-05 | 시간별 바람·풍향·돌풍·파고·**파주기·파향**·수온 예보 | Must | **최소 2주(현재 16일)** 시간별 값이 리스트로 표시된다 | 구현(Open-Meteo 16일) |
| FR-06 | 지역 검색·선택·즐겨찾기 | Must | 이름/해역 검색, 별표 토글, 선택 시 전 화면 반영 | 구현 (전국 41개 지점) |
| FR-07 | 홈 대시보드 요약 | Must | 물때+다음 만조/간조+현재 바람·파고가 한 화면에 보인다, 상단 버튼으로 지역 전환, 날짜 띠로 과거 2주~미래 2주 이동 | 구현 |
| FR-08 | 실데이터 연동(조석예보 고저조) | Must | 관측소 코드 기준 실제 조석예보가 표시된다, 실패 시 합성 폴백 | **구현** (data.go.kr, 키 주입 시 활성) |
| FR-09 | 실데이터 연동(Open-Meteo 기상) | Must | 좌표 기준 실제 예보가 표시된다, 실패 시 합성 데이터 폴백 | **구현** |
| FR-10 | 즐겨찾기·선택 지역 영속화 | Should | 앱 재시작 후에도 유지된다 | **구현** (shared_preferences) |
| FR-11 | 오프라인 캐시 열람 | Should | 비행기 모드에서 마지막 데이터가 보인다 | **구현** (조석·날씨·낚시지수 모두) |
| FR-12 | 바람 지도(파티클 애니메이션) | Must | 날씨 탭 첫 화면이 화면 전체를 채우는 지도, 지도 아무 곳이나 탭하면 가장 가까운 지점이 선택되고 하단 바에 요약이 뜨며 탭하면 상세 목록이 바텀시트로 펼쳐짐(윈디 방식), 손가락으로 확대/축소해도 풍속 색상이 유지되고 확대하면 지역명이 더 보임, 바람 세기에 따라 흐름선 길이가 달라짐, 시간 스크러버로 2주간 시간대 이동 | **구현** |
| FR-13 | 위험 기상 푸시 알림 | Could (v0.5) | 설정 조건 초과 시 알림이 온다 | 미구현 |
| FR-14 | 정확 음력(천문력) 적용 | Should (v0.3) | KHOA 제공 음력/물때와 일치한다 | 근사치 사용 중 |
| FR-15 | 조석 예보 1년 제공 | Must | 오늘 기준 ±1년 날짜의 만조/간조·조위를 조회할 수 있다, 범위 밖은 명시적 안내 | 구현 |
| FR-16 | 단순 물때 2년 제공 | Must | 미래 2년까지 날짜별 물때 명칭을 조회할 수 있다(조석 없이) | 구현 |
| FR-17 | 해역별 물때식 구분 | Must | 서해 = 7물때식, 남해·동해·제주 = 8물때식으로 표시되고 배지에 방식이 명기된다 | 구현 |
| FR-18 | 바다낚시지수 표시 | Should | 지점별 오전/오후 5단계 낚시지수가 홈에 표시된다(해역 기준 어종이 여럿이면 여러 종을 함께 표시), 실패 시 합성 폴백 | **구현** (실데이터, 최근접 포인트·어종별) |
| FR-19 | 강제 업데이트 게이트 | Should | 원격 설정 플래그를 켜면 앱 재배포 없이 기존 설치 기기의 실행을 막고 업데이트 안내+스토어 링크만 보여준다, 설정 확인 실패 시(오프라인 등)는 항상 정상 실행 | **구현** (`core/remote_config/`) |
| FR-20 | 육상 날씨 예보 탭 | Should | 지역 육상 날씨를 24시간·15일 예보 + 부가정보(2시간 강수 나우캐스트·바람/돌풍·습도·자외선·가시거리·일출몰·공기질)로 제공한다. 기상청 단기예보 우선 + Open-Meteo(전세계·15일) 보조, 실패 시 캐시→합성 폴백. 직접 그린 날씨 아이콘. (5분 갱신·기상특보는 무료 무키 소스 부재로 미지원) | **구현** (`features/kma_weather`) |
| FR-21 | 설정(템플릿/정보) 탭 | Should | 한 화면에 템플릿(앱 테마색·밝기 모드·배경 그래픽)과 정보(문의 메일·버전·릴리즈일·광고 제거·정책 및 이용약관)를 제공한다 | **구현** (`features/settings`) |
| FR-22 | 지역 선택 공용 액션 | Must | 모든 탭 우측 상단에서 현재 지역명 표시 + 지역 변경이 가능하다(별도 지역탭 제거) | **구현** (`RegionSelectorAction`) |

### 2.2 비기능 요구사항 (NFR)

| ID | 분류 | 요구사항 |
|---|---|---|
| NFR-01 | 플랫폼 | Android 8.0(API 26) 이상 우선 지원, 코드베이스는 iOS 확장 가능해야 함 → Flutter 채택 |
| NFR-02 | 성능 | 홈 화면 초기 표시 2초 이내(캐시 기준), 그래프 60fps 렌더 |
| NFR-03 | 가용성 | API 장애 시 캐시/목 데이터로 degrade, 오류 메시지 한국어 표기 |
| NFR-04 | 보안 | API 키는 소스에 커밋 금지, `--dart-define` 주입 (`core/config/env.dart`) |
| NFR-05 | 국제화 | 초기 한국어 전용, 문자열 하드코딩은 추후 l10n 전환 가능 구조 유지 |
| NFR-06 | 품질 | CI에서 format/analyze/test 통과 필수, 핵심 로직(물때 계산) 단위 테스트 유지 |
| NFR-07 | 비용 | 무료 배포 — 무료·공공 API(KHOA, Open-Meteo)만 사용 |
| NFR-08 | 접근성 | 시스템 다크 모드 대응(구현), 최소 터치 영역 48dp |

### 2.3 도메인 규칙 정리

- **물때는 해역별로 셈법이 다르다 (FR-17)**:
  - 서해(7물때식): 음력 1일 = 7물. 10일·25일 = 1물, 8일·23일 = 조금, 9일·24일 = 무시.
  - 남해·동해·제주(8물때식): 음력 1일 = 8물. 9일·24일 = 1물, 8일·23일 = 조금(무시 없음).
  - 동해는 조차가 작아 물때의 실질 의미가 약하다 — 표기는 8물때식을 따른다.
- **데이터 제공 범위**: 조석(만조/간조·조위) = 오늘 기준 ±1년(FR-15),
  단순 물때 = 미래 2년(FR-16), 해양 기상 = 16일(FR-05).
- **사리/조금**: 삭망(신월·보름) 직후 조차 최대(사리), 상·하현 부근 최소(조금).
- **풍향 표기**: 기상 관례(불어오는 방향) 사용, 화살표는 불어가는 방향으로 표시.
- **조위 기준면**: KHOA 연동 시 약최저저조면(DL) 기준 cm 사용.

### 2.4 범위 제외 (v1.0까지 하지 않는 것)

- 회원가입/로그인, 커뮤니티(조황 공유)
- 유료 구독, 광고
- 해외 지역 지원
- 실시간 CCTV/조황 영상
