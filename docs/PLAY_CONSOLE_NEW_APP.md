# Play Console "새 앱 만들기" 등록 가이드

Play 개발자 계정 인증이 끝난 뒤, **Console에 실제로 입력할 값**을 순서대로
모아 둔 문서다. 값은 그대로 복사해 붙여 넣으면 된다.

전체 런칭 흐름(키스토어·AdMob·AAB 빌드)은
[PLAY_STORE_LAUNCH.md](PLAY_STORE_LAUNCH.md)를 본다. 이 문서는 그중
**7단계(Play Console 등록)** 만 상세히 푼 것이다.

## 2. 앱 설정 (대시보드 왼쪽 "앱 설정" 항목들)

순서대로 다 채워야 출시 버튼이 열린다.

### 2-1. 앱 액세스 권한
→ **모든 기능을 제한 없이 사용할 수 있음**

(로그인·회원가입이 없고 지역 선택만으로 전 기능이 동작한다.)

### 2-2. 광고
→ **예, 앱에 광고가 있습니다**

(AdMob 배너가 물때 화면·설정 화면 하단 두 곳에 들어간다.)

### 2-3. 콘텐츠 등급
설문 응답:

| 질문 | 답 |
|---|---|
| 이메일 주소 | `bisan74@gmail.com` |
| 카테고리 | **참고, 뉴스 또는 교육용** (또는 유틸리티) |
| 폭력·성적 콘텐츠·욕설·마약·도박 등 모든 항목 | **아니요** |
| 사용자 간 상호작용(채팅·소셜) | **아니요** |
| 위치 공유 | **아니요** (기기 위치를 다른 사용자와 공유하지 않는다) |
| 개인정보 공유 | **아니요** |
| 디지털 구매 | **아니요** |

결과는 전체 이용가 / 3+ 로 나온다.

### 2-4. 타겟 고객층 및 콘텐츠
→ **만 18세 이상**만 선택 (권장)

> **왜 18세 이상인가**: 18세 미만 연령대를 하나라도 선택하면 Google Play
> **Families 정책**이 적용되어 광고도 "가족용 인증 광고 SDK"만 쓸 수 있고
> 심사가 훨씬 까다로워진다. 일반 AdMob 배너를 쓰는 지금 구성에서는 18세
> 이상만 선택하는 게 가장 단순하고 안전하다. (앱이 성인용이라는 뜻이 아니라
> "아동을 겨냥해 만들지 않았다"는 선언이다.)

이어지는 질문:
- 아동의 관심을 끌 수 있나요? → **아니요**
- 스토어 등록정보가 아동에게 어필하나요? → **아니요**

### 2-5. 뉴스 앱
→ **아니요** (기상 정보 앱이지 뉴스 앱이 아니다)

### 2-6. 코로나19 접촉자 추적·건강 앱
→ **아니요**

### 2-7. 데이터 보안 (Data safety)

**앱 자체는 개인정보를 수집하지 않지만 AdMob SDK가 수집**하므로 "예"로 답한다.

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | **예** |
| 전송 중 데이터가 암호화되나요? | **예** |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **아니요** (앱 삭제 시 기기 내 데이터 제거) |
| 독립적인 보안 검토를 받았나요? | 아니요 |

수집·공유 항목:

| 데이터 유형 | 수집 | 공유 | 필수? | 목적 |
|---|---|---|---|---|
| 위치 → **대략적인 위치** | O | O | 선택 | 광고 또는 마케팅 |
| 기기 또는 기타 ID → **기기 또는 기타 ID** | O | O | 필수 | 광고 또는 마케팅, 분석 |
| 앱 활동 → **앱 상호작용** | O | O | 필수 | 광고 또는 마케팅, 분석 |

> **주의**: 앱이 "현재 위치" 버튼으로 쓰는 GPS는 기기 안에서만 쓰고 서버로
> 보내지 않으므로 여기에 적지 않는다. 위 표의 "대략적인 위치"는 **광고 SDK가
> IP 기반으로 수집하는 것**이다.
>
> 정확한 항목은 AdMob 공식 안내를 확인한다:
> https://support.google.com/admob/answer/11170392

### 2-8. 정부 앱 / 금융 기능 / 헬스 앱

## 5. 심사에서 자주 걸리는 것 (미리 피하기)

| 위험 | 대응 |
|---|---|
| 개인정보처리방침 URL이 404 | 등록 전 브라우저로 직접 열어 확인 |
| 데이터 보안 양식이 실제 SDK 동작과 다름 | AdMob 항목(위치·광고 ID·앱 상호작용) 반드시 포함 |
| "공식", "정부 제공" 같은 표현 | 쓰지 않는다. 데이터 **출처**가 공공기관이라고만 적는다 |
| 다른 앱 이름 언급 | 설명·스크린샷에 경쟁 앱 이름을 넣지 않는다 |
| 스크린샷에 기기 프레임·과장 문구 | 실제 화면 그대로 올린다 |
| 예보를 단정적으로 표현 | "100% 정확", "실시간" 같은 표현을 피한다 |
| 안전 관련 고지 누락 | 자세한 설명에 "출항 전 기상특보 확인" 문구가 이미 들어 있다 — 지운다면 다시 넣는다 |

## 6. 출시 후

- 스토어 URL이 `https://play.google.com/store/apps/details?id=com.badamobile.bada_mobile`
  로 열리는지 확인 (공개 저장소 `app_gate.json`의 `storeUrl`이 이 주소다)
- AdMob 광고가 실제로 뜨는지 확인. 새 광고 단위는 노출까지 **몇 시간** 걸릴 수
  있고, 그동안은 광고 자리에 앱 소개 박스가 보인다(정상 동작)
- AdMob → 앱 → "스토어에 등록된 앱과 연결"로 실제 스토어 항목과 연결
